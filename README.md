# Weird Animals
 
A React app to store, rank and search through a collection of weird and wonderful animals. Built with **React**.
 
## How to run
 
```bash
npm install
npm run dev
```
 
Then open `http://localhost:5173`.
 
## Data format
 
Each animal in `animals.json` looks like this:
 
```json
{
  "id": 1,
  "name": "Axolotl",
  "description": "A pink smiling salamander from Mexico.",
  "image": "/images/axolotl.jpg",
  "rating": 5
}
```
